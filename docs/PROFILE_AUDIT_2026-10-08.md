# Audit profil — 8 Oktober 2026

Audit ini mencakup profil sendiri, header profil publik, editor nama/foto, pembuatan profil setelah autentikasi, visibilitas profil, playlist pajangan, dan penggunaan identitas pada kartu berbagi. Tema Gratify, navigasi sosial, QR profil, serta fitur musik yang sudah ada dipertahankan.

## Temuan dan perbaikan

- **Draft edit mengambil cache lama.** Editor lama mengisi nama dan foto langsung dari DataStore meski profil server sudah dimuat. Editor kini memakai identitas yang tampil dari profil server. Foto kosong pada server dianggap sebagai penghapusan, sehingga tidak diisi kembali oleh foto cache. Identitas cache hanya dipakai bila pemilik pustaka cocok dengan akun aktif; kartu berbagi dan menu profil juga memakai identitas yang sama.
- **Isian pembuatan profil dapat berubah saat disimpan.** Pembuatan dan edit kini memakai satu model pengajuan. Nama/foto diambil sebagai satu snapshot, input dikunci saat menyimpan, ketukan berulang diabaikan, dan identitas akun diperiksa sebelum serta setelah setiap tahap. Nama dipangkas spasi awal/akhir, wajib terisi, dan dibatasi 64 karakter. Form tidak ditutup saat gagal, dengan kesalahan yang terlihat dan kesempatan mencoba lagi.
- **Simpan terpisah dari cache lokal.** Metadata autentikasi dan profil publik disimpan sebelum cache. Kegagalan cache tidak dilaporkan sebagai kegagalan simpan server yang sudah terkonfirmasi. Penyimpanan metadata, unggahan avatar, dan profil publik bukan transaksi lintas layanan; kegagalan di tengah tahap tetap dapat membutuhkan percobaan ulang.
- **Foto tidak memiliki alur hapus yang jelas.** Tersedia pilih dan hapus foto, dengan inisial ketika tanpa foto. Payload identitas mengirim `avatar_url: null` secara eksplisit untuk benar-benar menghapus foto lama, sekaligus hanya menulis id/nama/foto agar catatan, aktivitas, dan privasi tidak ikut diubah. Foto lokal dapat dipratinjau di editor; avatar publik tetap hanya menerima URL bucket avatar. Gambar yang gagal dimuat kembali ke inisial.
- **Aktivitas musik dapat menimpa identitas.** Pembaruan aktivitas sebelumnya membawa nama/foto dari cache. Pembaruan sekarang hanya menulis empat field aktivitas; berhenti memutar mengirim null eksplisit untuk video/judul/artis. Nama dan foto yang baru diedit tidak ikut ditimpa oleh heartbeat.
- **Form edit kurang nyaman pada layar kecil dan keyboard.** Editor baru dapat digulir, mengikuti ruang keyboard, memiliki batas lebar 600 dp, label dan petunjuk nama, pesan gagal, serta tombol minimum 48–52 dp. Perubahan yang belum disimpan dikonfirmasi saat menutup. Pembuatan profil menggunakan komponen form yang sama.
- **Header dan tombol terlalu rapat.** Avatar/header dibuat lebih ringkas, nama diberi ruang sendiri, jumlah pengikut/mengikuti memiliki target minimum 48 dp, dan tombol Edit profil/Visibilitas/Pilihan lainnya diberi label aksesibilitas serta target 48 dp. Lebar konten profil sendiri dan publik dibatasi 760 dp.
- **Privasi belum menyampaikan seluruh dampaknya.** Label artis kini menyebut aktivitas mendengarkan yang memang memakai flag server yang sama. Seluruh baris dapat digunakan sebagai switch dengan status aksesibilitas. Pilihan hanya aktif setelah profil sendiri dimuat, nilai berubah setelah server mengonfirmasi, kegagalan tampil di sheet, dan profil yang belum siap memiliki aksi coba lagi. Nilai profil dalam state diperbarui agar pratinjau mengikuti pilihan terkonfirmasi.
- **Daftar playlist pajangan rentan gagal memuat tanpa pemulihan.** Pembacaan menangani exception/timeout, memeriksa akun sebelum memperbarui pilihan, dan membersihkan sheet/pilihan saat akun berubah. Pembaruan playlist memakai akun yang ditangkap saat aksi dimulai dan batas waktu. Picker dapat digulir, tidak ditutup saat menyimpan, serta playlist yang belum dipilih diberi label “Belum dipajang”.
- **Identitas dan kegagalan berbagi.** Kartu berbagi, menu, dan QR memakai nama/foto yang tampil dari profil. Kegagalan clipboard atau berbagi kartu memberikan umpan balik; isian/form tidak dibuat seolah berhasil. Tidak ada tautan yang dikirim ke orang lain selama audit.

## Validasi

**79 tes lulus, tanpa kegagalan atau error**. Rincian: ProfileEditorRegressionTest 8, ProfileEditorRenderTest 5, ProfileFixRegressionTest 19, ProfileStatusRenderTest 3, ProfileDiscoveryRegressionTest 8, ProfileLinksTest 4, ProfileLoginReturnTest 4, AuthRenderTest 4, NavigationRegressionTest 13, dan ProfileReadRegressionTest 11. Hasil suite tersedia dalam `artifacts/profile-2026-10-08/test-summary.json`.

Tes model meliputi snapshot pengajuan yang tidak berubah saat simpan, ketukan berulang, pergantian akun selama unggah, simpan gagal lalu coba lagi, penghapusan foto, foto tidak dapat diproses, validasi nama, dan cache gagal setelah simpan server. Tes HTTP dengan server lokal memeriksa payload identitas dan null penghapusan avatar, serta memastikan pembaruan aktivitas tidak membawa nama/foto. Tes privasi memeriksa nilai terkonfirmasi dan kegagalan yang mempertahankan pilihan sebelumnya. Tes render memakai lebar 320/390/1100 dp dan ukuran teks 150%; header juga diperiksa dengan teks besar 200% pada 360 dp.

Build APK debug Android dan kompilasi desktop berhasil dalam **1 menit 38 detik**, dicatat di `artifacts/profile-2026-10-08/validation-complete.log`. APK universal terakhir dibuat **8 Oktober 2026 pukul 20.32.41 WIB**, di `androidApp/build/outputs/apk/debug/androidApp-universal-debug.apk`. Ukuran dan SHA-256 seluruh APK tersedia di `apk-verification.json`.

APK akhir dipasang pada emulator Android dengan page size **16 KB (16384 byte)**. Fixture visual memakai komponen produksi, dengan identitas Nara dan state sintetis. Alur profil → edit, perubahan nama, tombol kembali yang menutup keyboard terlebih dulu, konfirmasi buang perubahan, lanjut edit dengan draft yang tetap ada, tampilan gagal simpan, profil → privasi, dan ketukan seluruh baris switch berhasil. Tombol Simpan tetap terlihat di atas keyboard. Buffer crash kosong selama pemeriksaan. Bukti: `android-smoke-summary.json`, `android-profile.png`, `android-editor.png`, `android-editor-keyboard.png`, `android-discard.png`, `android-editor-failure.png`, `android-privacy.png`, serta dump UI XML di folder artefak yang sama. Status gagal simpan pada fixture Android sengaja disimulasikan; perilaku simpan/coba lagi diuji pada model dan payload HTTP lokal.

Pemeriksaan tidak membuat akun, mengganti profil nyata, mengunggah foto ke server produksi, mengirim pesan, atau mengubah migrasi database. Fixture Android khusus debug memakai data contoh dan komponen UI produksi. Perangkat fisik dan pengiriman profil melalui server produksi bukan bagian pemeriksaan otomatis ini.
