Gratify 2.1.5 menyertakan perubahan berikut:

- Kolaboratif, Blend, dan folder dinonaktifkan sementara. Playlist biasa tetap tersedia; sumber fitur disimpan untuk pengembangan berikutnya.
- Situs developer dan tautan blog sekarang memakai https://tanheradhe.my.id.
- Tautan terpisah SimpMusic dihapus dari halaman kredit. Deskripsi sumber asal, ikon kode, dan lisensi tetap dicantumkan.

Unduh **Gratify.apk** untuk APK universal atau **Gratify-2.1.5-release-arm64-v8a.apk** untuk perangkat ARM64. APK memakai nama Gratify, paket `com.tan.gratify.next`, dan kunci rilis successor yang sama. Aplikasi lama dengan paket `com.tan.gratify` dapat tetap terpasang berdampingan.

Metadata pembaruan tersedia pada `gratify-update.json`; hash berkas ada pada `SHA256SUMS.txt`. Sumber Android yang sesuai dengan APK tersedia pada **Gratify-2.1.5-source.zip**, termasuk perubahan lokal. Gunakan arsip ini sebagai sumber rilis; arsip tag otomatis GitHub dapat merujuk commit repository sebelumnya.

Validasi: 13 tes terpilih untuk halaman kredit dan pembatasan fitur, build rilis dengan optimasi R8, lint vital, tanda tangan APK, serta alignment ZIP/native 64-bit 16 KB. Putaran ini belum mencakup pengujian pemutaran lama atau perangkat RAM 2–4 GB.
